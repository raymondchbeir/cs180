Overview

Most of this project is really about separating an image into different kinds of information.

I started with convolution and finite difference filters to pull out image derivatives and edges. From there I used Gaussian filters to control high and low frequencies, which leads naturally into sharpening, hybrid images, and finally multiresolution blending.

The part that clicked for me is that the Laplacian stack is basically splitting an image into bands of detail. Once both images are split into those bands, I can blend each band with a smooth mask and add everything back together.

Part 1.1

Convolutions from Scratch

01

I implemented convolution two ways. The first version uses four nested loops and explicitly computes every multiply-and-add. The second still loops over output pixels, but uses a NumPy slice for the local image patch and computes the dot product in one operation. In both cases I flip the kernel first and zero-pad the image so the output has the same size as the input.

4-loop version

Everything explicit

For every output pixel I loop over every kernel row and column. It is useful because the mechanics of convolution are completely visible, but it is slow because almost all of the work happens in Python loops.

2-loop version

Same idea, less Python

I still move over every image location, but I multiply the whole image patch by the flipped kernel at once. This is much faster, and SciPy's convolve2d is faster again because the implementation is optimized underneath Python.

Part 1.2

Finite Difference Edge Detection

02

I applied the finite difference filters to the cameraman image, then combined the derivatives using the gradient magnitude. Thresholding that magnitude gives a binary edge map. The threshold is a tradeoff: too low and texture/noise appears everywhere, too high and real edges disappear.

Part 1.3

Derivative of Gaussian

03

The raw finite difference result reacts to a lot of small intensity changes. Blurring first suppresses those high-frequency changes, so the derivative response becomes cleaner. I also convolved the Gaussian itself with Dx and Dy to make derivative-of-Gaussian filters and then applied those directly to the image. Aside from boundary behavior, the result matches blur-then-differentiate because convolution is associative.

Part 2.1

Image Sharpening

04

Sharpening comes from taking the high-frequency part of an image and adding it back to the original. I get the high frequencies by subtracting a Gaussian-blurred version from the original. Increasing the scale on that high-frequency component makes the result sharper, but too much starts to look artificial.

high frequencies = image − blur(image) sharpened = image + α · high frequencies

Taj Mahal

Blur then recover

For a second test I took an already sharp image, blurred it myself, and then sharpened the blurred image. The recovered image looks sharper than the blurred input, but information removed by the blur is not actually recreated. Sharpening boosts the remaining high-frequency contrast; it does not undo the blur perfectly.

Part 2.2

Hybrid Images

05

A hybrid image combines the low frequencies from one image with the high frequencies from another. Up close, the high-frequency image dominates because the fine details are visible. From farther away those details disappear and the low-frequency image becomes more noticeable. The alignment matters a lot, so I used two matching points to put the important features at similar scale and orientation before filtering.

Part 2.3

Gaussian & Laplacian Stacks

06

Unlike a pyramid, my stack keeps every level at the same image size. The Gaussian stack repeatedly smooths the image. The Laplacian stack is formed by subtracting consecutive Gaussian levels, so each level stores a band of detail that disappeared between those blur scales. I keep the final Gaussian level as the low-frequency residual, which means summing the Laplacian stack reconstructs the image.

GaussianG₀, G₁, G₂, … become progressively smoother.
LaplacianLᵢ = Gᵢ − Gᵢ₊₁, with the last Gaussian kept as the residual.
ReconstructionAdd all Laplacian levels back together.

Blending Across Frequencies

07

For the apple and orange I use a half-image mask and build a Gaussian stack of that mask too. At every level, the mask chooses how much of the apple Laplacian and orange Laplacian to keep. The coarse mask levels have a wide transition, while the fine levels preserve local detail. I add all the blended Laplacian levels at the end to get the final Oraple.

Bᵢ = Mᵢ · Lapple,i + (1 − Mᵢ) · Lorange,i final blend = Σ Bᵢ

Part 2.4

Multiresolution Blending

08

I used the same stack-based blending process on two custom examples. The first uses a shifted vertical mask. The second uses an irregular oval mask, which was useful because I wanted to keep the planets in the middle instead of splitting the image along a straight line.

Custom blend #1

Starship + Apollo 11

I aligned the rockets using the top and bottom of each rocket as the two corresponding points. After alignment, I placed Starship on the left and Apollo 11 on the right. I moved the split slightly left to put the seam in a better part of the scene, then blurred the mask across the stack so the transition happens over multiple spatial scales instead of as a hard cut.

Custom blend #2 · irregular mask

Planet Blend

For this one a straight split did not make sense because the part I wanted to preserve was around the center. I made an oval mask around that region. A hard oval still left a very obvious seam, so I blurred the oval itself before building its Gaussian stack. That gave even the first mask level a gradual transition and made the final composite much smoother.

What I took away from this

The mask matters just as much as the image stacks. If the mask has a hard boundary at the finest level, a difficult pair can still look pasted together. For the irregular blend, softening the initial oval before creating the mask stack was what finally removed most of the visible seam.

Convolution from scratch

4-loop convolutionconv4
def conv4(image, kernel):
    flipped_kernel = np.flip(kernel)
    pad_h = kernel.shape[0]//2
    pad_w = kernel.shape[1]//2
    padded_image = np.pad(
        image,
        ((pad_h, pad_h), (pad_w, pad_w)),
        mode = 'constant'
    )
    image_output = np.zeros((image.shape[0], image.shape[1]))

    for i in range(image.shape[0]):
        for j in range(image.shape[1]):
            output = 0
            for n in range(kernel.shape[0]):
                for m in range(kernel.shape[1]):
                    output += flipped_kernel[n,m] * padded_image[n+i,m+j]
            image_output[i,j] = output

    return image_output
2-loop convolutionconv2
def conv2(image, kernel):
    flipped_kernel = np.flip(kernel)
    pad_h = kernel.shape[0]//2
    pad_w = kernel.shape[1]//2
    padded_image = np.pad(
        image,
        ((pad_h, pad_h), (pad_w, pad_w)),
        mode = 'constant'
    )
    image_output = np.zeros((image.shape[0], image.shape[1]))

    for i in range(image.shape[0]):
        for j in range(image.shape[1]):
            image_output[i,j] = np.sum(
                flipped_kernel *
                padded_image[i:i+kernel.shape[0],
                             j:j+kernel.shape[1]]
            )

    return image_output

Gaussian and Laplacian stacks

Gaussian stackPart 2.3
def gaussian_stack(image, gaussian, levels):
    stack = [image]
    current = image

    for i in range(levels - 1):
        output = np.zeros_like(current)
        for c in range(current.shape[2]):
            output[:, :, c] = convolve2d(
                current[:, :, c],
                gaussian,
                mode = 'same',
                boundary = 'symm'
            )
        stack.append(output)
        current = output

    return stack
Laplacian stackPart 2.3
def laplacian_stack(g_stack):
    stack = []

    for i in range(len(g_stack) - 1):
        stack.append(g_stack[i] - g_stack[i+1])

    stack.append(g_stack[-1])
    return stack
